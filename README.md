# Forma — Mini E-commerce with Redux Toolkit

## Run locally
1. Install Node.js (LTS) if it is not already installed.
2. Extract this folder.
3. Open a terminal inside `mini-ecommerce-redux`.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite.

## Features
- React Router DOM pages: Home, Products, Cart, About, Checkout, Order Success and 404
- Redux Toolkit `cartSlice` with add/remove/increase/decrease/clear reducers
- Navbar cart count and cart total
- Add-to-cart confirmation message
- Search and category filter
- localStorage persistence
- Checkout demo using `useNavigate`
- Responsive styling

Product photos use remote Unsplash image URLs, so an internet connection is needed for the photos.
